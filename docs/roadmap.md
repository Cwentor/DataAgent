# 演进里程碑

| 三期 | 同比/环比双窗口 CTE | ✅ |
| 四期 | 多事实表语义模型与跨表比率指标 | ✅ |
| 五期 | 表级、列级、行级 RLS | ✅ |
| 六期 | DSL 解释与可视化推荐 | ✅ |
| 七期 | Web 可视化 UI | ✅ |

| 九期 | 意图路由与语义澄清反问 | ✅ |
